# Bananarang — Fabric mod project

## Goal
Minecraft Java Edition mod, to be published on CurseForge and Modrinth (Java mods
cannot be sold on the Bedrock Marketplace; monetization is via the sites' creator
reward programs).

## Environment
- JDK 25 (Temurin, user-local): `~/.local/jdks/jdk-25.0.3+9` — Minecraft 26.x requires Java 25.
  Not on the default PATH; prefix Gradle commands with:
  `export JAVA_HOME=~/.local/jdks/jdk-25.0.3+9 && export PATH="$JAVA_HOME/bin:$PATH"`
- Minecraft 26.1.2, Fabric Loader 0.19.3, Fabric API 0.151.0+26.1.2 (see `gradle.properties`)
- Version reference: https://fabricmc.net/develop

## Commands
- Build: `./gradlew build` (jar lands in `build/libs/`)
- Run dev client: `./gradlew runClient`
- Run dev server: `./gradlew runServer`

## The mod
Mod id `bananarang`, package `dev.piotr.bananarang`. A throwable banana
(`BananaItem`) that flies as a boomerang projectile (`BananarangEntity`):
flies straight for 16 ticks destroying all breakable blocks (skips
bedrock-like blocks with destroySpeed < 0) and damaging entities in its
path, then homes back to the thrower and returns to their inventory.
Banana texture + mod icon are generated by `scripts/gen_texture.py`.

## 26.x API notes (differ from 1.21-era docs)
- Mojang mappings by default; no `mappings`/`modImplementation` lines in build.gradle.
- `ResourceLocation` is renamed `Identifier` (still in `net.minecraft.resources`).
- Some classes moved to per-class subpackages (e.g. `projectile/throwableitemprojectile/`).
- Items need `Item.Properties().setId(ResourceKey<Item>)` before construction.
- Damage API: `entity.hurtServer(ServerLevel, DamageSource, float)`.
- Creative tabs are data-driven; no static keys in `CreativeModeTabs`. Use Fabric's
  `CreativeModeTabEvents.modifyOutputEvent(ResourceKey.create(Registries.CREATIVE_MODE_TAB, ...))`.
- Fabric's `EntityRendererRegistry.register` is deprecated (no vanilla replacement found yet; still works).
- To check any API signature: `javap -cp ~/.gradle/caches/fabric-loom/minecraftMaven/net/minecraft/minecraft-common-deobf/26.1.2/minecraft-common-deobf-26.1.2.jar <class>`
  (client classes: `minecraft-clientonly-deobf`).
